# Social-Network-Analysis-Tool-

A C++ simulation and analysis tool for modeling social networks with weighted friendships, shortest-path calculations, and community detection.

This repository provides a file-based simulator that models a dynamic user graph, computes top friend suggestions, and performs graph analyses using BFS and DFS variants (functions named BFS10 and DFS11 in the codebase).

Features
Implemented in modern C++.
Weighted friendships (edge weights represent relationship strength or interaction frequency).
Shortest-path computations between users.
Community detection / clustering utilities to identify groups.
File-based input/output for easy batch simulations.
Dynamic user addition/removal and edge updates.
Top-3 friend suggestions using BFS10 / DFS11 algorithms.
